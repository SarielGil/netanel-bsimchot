# נתנאל בשמחות — אתר השקה

אתר סטטי בעברית עבור נתנאל הנסב, “נתנאל בשמחות”, עם מיקוד ראשי בהכנסת ספר תורה ומיקוד משני בחתונות חרדיות ודתיות בהפרדה מלאה.

## הרצה מקומית

```bash
python3 -m http.server 4173
```

לאחר מכן פותחים `http://localhost:4173`.

## לפני רכישת דומיין או קמפיין

יש לעבור עם נתנאל על `RESEARCH.md`, לאשר את הטלפון, התמונה, ההמלצות, אזורי השירות, רכיבי הציוד והניסוחים. לאחר בחירת דומיין יש לעדכן את כתובות ה־canonical, Open Graph, Schema, `robots.txt` ו־`sitemap.xml`.

## מקורות נכסים

- תמונת נתנאל והלוגו: העמוד הציבורי שלו באתר “מילה טובה”.
- תמונות הסרטונים: ערוץ YouTube הציבורי של נתנאל והסרטון שפורסם עבורו.
- תמונת הפתיחה: אילוסטרציה מקורית שנוצרה עבור האתר באמצעות OpenAI Imagegen; היא מסומנת באתר כאילוסטרציה.
